# Ply

A chess opening trainer for the phone: your lines, the traps inside them and your own mistakes, on a spaced-repetition schedule. Installable PWA.

**Status:** design build running on demo data. See `docs/PROGRESS.md` for what is real and what is not, `docs/BRIEF.md` for the full spec and `docs/DESIGN.md` for the design system.

```
cd app
npm install
npm run dev      # http://localhost:5173/ply/
npm run build
npm run shots    # screenshots into docs/screenshots
```

Live: https://eben-vranken.github.io/ply/
